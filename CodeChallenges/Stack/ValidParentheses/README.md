# Challenge: Valid Parentheses

## Source

Original problem: [Valid Parentheses](https://neetcode.io/problems/validate-parentheses/question)

## Problem Summary

Validate a string containing only the following characters: ``(``, ``)``, ``[`` , ``]``, ``{``, ``}``.
The string is valid if:
1. Each opening paren is closed by the same type of closing paren.
1. Each pair of parens are closed in the proper order.
1. Each close paren has a preceding open paren of the same type.

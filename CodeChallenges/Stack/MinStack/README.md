# Challenge: Min Stack

## Source

Original problem: [Min Stack](https://neetcode.io/problems/minimum-stack/question)

## Problem Summary

Implement a class that functions as a stack containing integers with the added ability to see the minimum value in the stack regardless of it's position.
The class should implement the following methods:

- ``void Push(int value)`` Pushes the int onto the stack.
- ``void Pop()`` Removes the top int from the stack.
- ``int Top()`` Gets the top int of the stack without removing it.
- ``int GetMin()`` Gets the minimum value found in the stack.

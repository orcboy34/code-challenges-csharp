# Challenge: Evaluate Reverse Polish Notation

## Source

Original problem: [Evaluate Reverse Polish Notation](https://neetcode.io/problems/evaluate-reverse-polish-notation/question)

## Problem Summary

Evaluate an array of strings that represent an arithmetic expression in [Reverse Polish Notation](https://en.wikipedia.org/wiki/Reverse_Polish_notation) and return the result.

## Assumptions and Constraints

- The array will contain a valid expression.
- The only strings in the array will be "+", "-", "*", "/", and valid integers which could be positive or negative.

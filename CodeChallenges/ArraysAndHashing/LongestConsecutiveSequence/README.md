# Challenge: Longest Consecutive Sequence

## Source

Original problem: [Longest Consecutive Sequence](https://neetcode.io/problems/longest-consecutive-sequence/question)

## Problem Summary

Find and return the length of the longest consecutive sequence of integers in a given array.
To be considered consecutive each number in the sequence must be one greater than the previous number.

## Assumptions and Constraints

- The supplied array may:
  - Be unordered.
  - Contain duplicates.
  - Be empty.
